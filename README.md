# ARUNIKA LIVING — Website Furnitur Modern & Elegan

Website e-commerce katalog furnitur kontemporer yang dirancang dengan estetika modern, minimalis, dan mewah (*Scandinavian-Japandi luxury*).

## ✨ Fitur Utama
- **Struktur Halaman Presisi**:
  - *Top Announcement Bar*: Bebas ongkir & navigasi bantuan.
  - *Main Navigation*: Brand logo, menu navigasi, tombol pencarian, disukai (*wishlist*), dan keranjang (*cart drawer*).
  - *Hero Spotlight*: Fotografi editorial ruang tamu dengan tajuk "FURNITUR TERFAVORIT".
  - *Asymmetric Showcase (Row 1 & 2)*: Kombinasi kartu produk dan banner *lifestyle* bergaya editorial ("HUNIAN MODERN" & "KENYAMANAN ALAMI").
  - *Trio Product Grid*: Kartu produk bersih dengan foto studio latar putih, tombol `+ Keranjang` dan `Lihat Detail` yang rapi di bagian bawah.
  - *Footer*: Informasi showroom, kebijakan, koleksi, tautan sosial, badge App Store & Google Play, serta buletin email.
- **Interaktivitas Lengkap**:
  - Slide-out Cart Drawer dengan kalkulasi total Rupiah otomatis.
  - Wishlist counter & heart toggle.
  - Quick View Modal detail produk (material, dimensi, warna, kuantitas).
  - Search overlay modal.
  - Toast notification responsif.
  - Tampilan mobile responsif dengan drawer menu bersih (bebas blur).

## 🚀 Menjalankan Secara Lokal
Buka file `index.html` langsung di browser, atau jalankan server lokal:
```bash
node server.js
```
Lalu akses: `http://localhost:8088/`
